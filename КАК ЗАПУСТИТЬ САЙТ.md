# Как запустить сайт (очень просто)

## Способ 1: двойной клик (самый простой)

1. Откройте в Finder папку проекта `amir project` (она на Рабочем столе).
2. Дважды щёлкните по файлу **`Запустить сайт.command`**.
3. Откроется чёрное окно Терминала, а через секунду сам откроется браузер с сайтом.
4. **Не закрывайте чёрное окно, пока пользуетесь сайтом.** Это и есть «сервер» сайта.
5. Чтобы выключить сайт, закройте чёрное окно.

Если macOS пишет «не удаётся открыть, разработчик не проверен», нажмите по файлу **правой кнопкой → Открыть → Открыть**. Это нужно сделать только один раз.

## Способ 2: через Терминал вручную

1. Откройте программу **Терминал** (Cmd + Пробел → наберите «Терминал» → Enter).
2. Перейдите в папку проекта. Это **обязательно**: без этого сайт не найдётся.
   ```bash
   cd ~/Desktop/"amir project"
   ```
3. Запустите сервер:
   ```bash
   python3 -m http.server 8000
   ```
4. Откройте в браузере (Safari, Chrome): **http://localhost:8000/web/**
5. Чтобы выключить, нажмите в Терминале **Ctrl + C**.

## Частые проблемы

| Что видно | Что делать |
|---|---|
| `command not found: python` | Пишите `python3`, а не `python` |
| `Address already in use` | Порт 8000 уже занят (сервер уже запущен). Закройте старое окно Терминала или нажмите в нём Ctrl + C. Либо возьмите другой порт: `python3 -m http.server 8001` и адрес http://localhost:8001/web/ |
| В браузере список файлов или «404 File not found» | Сервер запущен **не из папки проекта**. Остановите его (Ctrl + C) и сделайте шаг 2 (`cd ...`) |
| Сайт пишет «Нет данных» | Выполните в папке проекта `python3 evaluate.py --set demo` и `python3 evaluate.py --set demo-prod`, затем обновите страницу |

## Как пользоваться сайтом

- **Слева внизу** выбирается набор данных: DEMO (12 диалогов) или «PROD (пример)» (10 диалогов), а после настоящего прогона ещё DEV и PROD.
- **Диалоги**: таблица всех диалогов. Нажмите на строку, чтобы открыть разбор.
- **Разбор диалога**: слева расшифровка (у звонков ещё плеер), справа балл и критерии. Нажмите на критерий, чтобы увидеть объяснение. Кнопка «Перейти к фрагменту» показывает нужную реплику.
- **Оспорить оценку**: кнопка под критериями. Выберите критерий, верное значение и напишите комментарий.
- **Апелляции**: здесь проверяющий принимает решение и нажимает «Зафиксировать финальную оценку».
- **Аналитика**: общая картина по всем диалогам.
- **Чек-листы**: критерии и формула балла.
